### 详细说明（商店正文草稿）

**Web3 Wallet 是一款本地自托管的 EVM 浏览器钱包。**

助记词与私钥只保存在你的浏览器扩展中：导入时使用口令加密，密文写入浏览器本地存储；扩展不托管资产，也不会上传助记词、私钥或口令。扩展不提供云备份、代客找回或资产追回服务，请务必离线备份。

**主要能力**

- 导入助记词或私钥，管理多个 EVM 账户；账户包使用 PBKDF2 + AES-GCM 加密保存在本机。
- 支持 Ethereum、Sepolia、Arbitrum One、Optimism、Base、Polygon、BNB Smart Chain，并允许用户显式添加最多 20 个自定义 EVM RPC 网络。
- 面向 DApp 提供 EIP-1193 / EIP-6963；连接账户、消息签名、EIP-712 结构化签名与交易均需在扩展审批页确认。
- 会话级解锁：成功输入口令后，在可配置的空闲时间（1–120 分钟）内复用 background 内存中的解锁态；手动锁定、超时、Service Worker 休眠或浏览器重启后需重新验证。
- 已连接网站管理：按站点来源 / 公开地址搜索、按地址或授权范围分组，并导出仅含公开站点元数据的 CSV。
- TVM(Tron) 账户导入 / 列表（不接入签名）；多链地址生成器可本地派生 EVM / TVM / BTC 地址，便于离线核对，且不写入账户库。

**安全提示**

- 助记词 / 私钥丢失后无法找回；请先离线备份，再导入资产。
- 每次签名前核对链、地址、金额与授权内容；不要在不信任的网站批准签名。
- 自定义 RPC 节点会看到公开地址、查询与广播交易，请只使用你信任的节点。
- 加密资产与链上交易存在风险；本扩展不构成投资、法律或税务建议。
- 当前版本仅支持 EVM 签名；Tron 账户管理不接入签名，BTC 仅提供地址派生工具。

**隐私说明**

扩展不接入广告、分析或遥测服务，不出售用户数据。扩展只会在你主动查询余额、连接 DApp 或签名 / 广播交易时，向当前链 RPC 发送公开地址、查询参数与已签名交易。完整说明见商店隐私政策链接。

## 2. 截图与宣传图脚本

### 2.1 截图规范

- 建议尺寸：**1280×800**（PNG / JPEG，商店也接受 640×400）；至少 1 张，建议 4–5 张。
- 使用**干净的测试浏览器配置**与无资产测试账户；不要出现真实助记词、私钥、口令、余额、API key、RPC URL 中的访问凭据或个人信息。
- 固定 100% 缩放，隐藏书签栏与非必要扩展；不要出现 `chrome://extensions` 中的开发者个人信息。
- 截图中的地址使用测试生成的公开地址，并加「示例」说明；不要使用用户真实地址。
- 每张截图只表达一个重点，叠加简短中文标题时避免遮住关键按钮。

### 2.2 建议截图顺序

| #   | 文件建议名            | 页面 / 状态                                         | 文案重点                                             |
| --- | --------------------- | --------------------------------------------------- | ---------------------------------------------------- |
| 1   | `01-welcome`          | `tabs/welcome.html` 首次安装模式                    | 「本地自托管 · 先备份再导入」；展示安全底线与版本    |
| 2   | `02-sidepanel`        | 侧栏概览                                            | 展示 DApp 全局设置、账户入口与「安全与使用指南」     |

## 3. 商店「隐私实践」填写建议

> 以下为当前实现的填写口径；Chrome Web Store 表单与定义可能调整，提交前由发布者逐项核对。

| 项目                           | 建议口径                                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| 单一用途                       | 本地自托管 EVM 钱包：加密保存账户，并在用户确认后连接 DApp、签名与广播交易。                                        |
| 远程代码                       | **否**。所有 JavaScript 随扩展包发布，不动态加载远程脚本。                                                          |
| 出售用户数据                   | **否**。                                                                                                            |
| 将数据用于与单一用途无关的目的 | **否**。                                                                                                            |
| 将数据用于信用、贷款或保险     | **否**。                                                                                                            |
| 广告 / 分析 / 遥测             | **无**。                                                                                                            |
| 本地保存的数据                 | 加密账户包、公开地址、当前网络 / 自定义 RPC 配置、站点授权、解锁 TTL 与最近一次引导版本。                           |
| 传输给第三方的数据             | 仅在你主动使用时，向当前链 RPC 发送公开地址、查询参数与已签名交易；向 DApp 返回你批准的公开地址 / 签名 / 交易结果。 |
| 网站内容 / 浏览历史            | 不采集一般网页内容或完整浏览历史；仅在连接站点时处理当前 origin、标签页 ID 与授权范围。                             |
| 位置、健康、个人通信           | **不收集**。                                                                                                        |
| 数据保留                       | 本地保存至删除账户、撤销站点授权或卸载扩展；项目侧无账户数据副本。                                                  |
| 联系方式                       | `[发布前填写]`                                                                                                      |

**有限使用承诺（Limited Use）草稿：**

- 扩展处理的数据仅用于提供或改进其单一用途（本地钱包功能）。
- 不出售用户数据，不将数据用于个性化广告、信用评估或与单一用途无关的目的。
- 不因批准用途之外的目的允许人工读取用户数据；用户主动发起的链上请求除外。

## 5. 已知上架风险与后续

- **主机权限较宽**：当前 `host_permissions` 包含 `https://*/*`，用于访问用户配置的任意 HTTPS RPC。商店审核可能要求解释；后续可评估改为按自定义链申请 optional host permissions，避免一次性授权全部 HTTPS。
- **公开链接缺失**：隐私政策与支持链接尚未部署，属于发布前置项，不由扩展构建自动提供。
- **截图未纳入仓库**：实际截图依赖浏览器环境与测试账户；本文件只提供脚本，避免提交含敏感数据的图片。
- **Tron / BTC 能力边界**：Tron 当前仅账户导入 / 列表（不接入签名），BTC 仅地址派生；商店文案不得暗示已支持 Tron / BTC 钱包签名。
- **隐私政策非法律意见**：发布前请由发布者按适用法律与 Chrome Web Store 最新政策复核。
