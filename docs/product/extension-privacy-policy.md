# Web3 Wallet（本地自托管）隐私政策

> **状态**：P4-3 草稿，随扩展源码维护；**发布前必须**替换文末联系方式与公开 URL，并由发布者按适用法律及 Chrome Web Store 最新政策复核。
>
> **生效日期**：2026-10-25
>
> **适用范围**：Chrome 浏览器扩展 **Web3 Wallet（本地自托管）**（下称「本扩展」）。本政策不适用于本项目 Web 站点或服务端；使用 Web 站点时适用其单独政策。

---

## 1. 摘要

- 本扩展是**本地自托管 EVM 钱包**，不托管用户资产，不提供助记词 / 私钥找回服务。
- 助记词、私钥与导入口令**不会上传**；账户包加密后保存在浏览器本地存储。
- 本扩展不接入广告、分析或遥测服务，不出售用户数据。
- 仅当用户主动查询余额、连接 DApp 或签名 / 广播交易时，扩展才会向当前链 RPC 或 DApp 发送必要的公开数据。
- 用户可通过删除账户、撤销站点授权、清除扩展数据或卸载扩展来删除本地数据。

---

## 2. 本扩展在本地处理的数据

| 数据                                                    | 用途                                                       | 是否离开设备                                       |
| ------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------- |
| 加密账户包（EVM / TVM 公开地址、标签、密文、salt / iv） | 账户列表、默认账户选择、签名时本地解密                     | 否；仅公开地址在用户主动连接 / 查询时发送          |
| 助记词 / 私钥明文                                       | 仅在导入、解密签名期间短暂存在于扩展内存                   | 否                                                 |
| 导入 / 解锁口令                                         | 仅在本地派生加密密钥；**从不持久化**                       | 否                                                 |
| 当前网络、内置 / 自定义 RPC 配置                        | 切换链、只读查询与交易广播                                 | RPC 请求会发往对应节点；配置本身不上传             |
| 已连接站点授权                                          | 记录 origin、公开 EVM 地址、授权范围、标签页 ID 与过期时间 | 否；站点仅接收用户批准的公开地址 / 签名 / 交易结果 |
| 解锁 TTL、交易提交方式、工具栏打开方式、引导版本等设置  | 本地功能偏好                                               | 否                                                 |

补充说明：

- 账户包使用 **PBKDF2（SHA-256）+ AES-GCM** 加密后写入 `chrome.storage.local`；口令不写入存储，也不发送到任何服务器。
- 会话级解锁时，解密后的可签名账户只保存在扩展 **background 内存**中，按公开地址隔离；手动锁定、空闲超时、Service Worker 休眠或浏览器重启后失效。
- 自定义 RPC URL 可能包含节点访问凭据（如 API key），因此按用户填写原文保存在本机；扩展列表只展示 host，开发日志不记录完整 URL。

## 3. 数据何时离开设备

本扩展当前不包含向本项目 Web 或服务端自动上报账户数据的功能。以下传输仅在用户主动操作时发生：

1. **区块链 RPC**：查询余额 / 区块号、连接 DApp、广播已签名交易时，扩展会向当前链的内置公共 RPC 或用户配置的自定义 RPC 发送公开地址、查询参数与已签名交易。第三方 RPC 节点可能记录请求来源、IP 与公开链上数据，其处理受该节点运营方政策约束。
2. **DApp**：用户连接站点并批准请求后，扩展会向该站点返回公开地址、签名或交易结果。DApp 对数据的后续处理受其自身隐私政策约束。
3. **用户主动导出**：用户导出已连接站点 CSV 时，文件仅保存到用户选择的本地位置；导出内容不含私钥、助记词、口令或 RPC 配置。

扩展**不会**：

- 上传助记词、私钥、口令或账户密文；
- 出售、出租或交易用户数据；
- 使用用户数据进行个性化广告、信用评估、贷款或保险决策；
- 在用户未发起链上操作时后台扫描网页内容或采集完整浏览历史；
- 加载远程 JavaScript 或动态下发可执行代码。

## 4. 权限与用途

| 权限                                         | 用途                                                                                   |
| -------------------------------------------- | -------------------------------------------------------------------------------------- |
| `sidePanel`                                  | 在浏览器侧栏显示钱包、设置与站点管理。                                                 |
| `scripting`                                  | 在本地开发域名白名单中注入 EIP-1193 provider 与隔离桥内容脚本。                        |
| `storage`                                    | 保存加密账户包、网络 / 解锁 / 界面设置、站点授权与引导版本。                           |
| `tabs`                                       | 打开账户 / 审批页；标签关闭时撤销该标签的站点会话。                                    |
| `webNavigation`                              | 检测主框架刷新并撤销旧页面的站点授权，避免旧授权被新文档继承。                         |
| `contextMenus`                               | 提供「打开侧边栏」右键菜单。                                                           |
| `windows`                                    | 创建独立的连接 / 签名 / 交易审批窗口。                                                 |
| 主机权限（HTTPS / 本地）                     | 访问内置公共 RPC 或用户配置的 EVM RPC；内容脚本仅在 localhost / 127.0.0.1 白名单注入。 |
| 资源暴露（`web_accessible_resources`，本地） | 允许本地开发 DApp 与扩展页面交互；不用于公网网页注入。                                 |

扩展不请求摄像头、麦克风、地理位置、剪贴板读取、下载或历史记录权限。

## 5. 共享、出售与有限使用

- **不出售、不出租、不交易**用户数据。
- 不与广告商、数据经纪商或信用机构共享用户数据。
- 除用户主动发起的 RPC / DApp 请求外，不向第三方披露本地保存的账户配置。
- 扩展对用户数据的处理仅限于提供或改进其单一用途（本地钱包功能），并遵守 Chrome Web Store 用户数据政策中的 Limited Use 要求。

---

## 6. 保留与删除

- 本地数据保留至用户主动删除账户、撤销站点授权、清除扩展数据或卸载扩展。
- 扩展不维护服务端账户数据副本，因此不存在需要向项目方申请删除的云端钱包数据。
- 用户自行导出或抄写的 CSV、助记词、私钥备份不在扩展控制范围内，删除扩展不会删除这些外部副本。
- 卸载扩展或清除浏览器扩展数据会移除本地加密账户；**如无备份将无法恢复**。

---

## 7. 安全

- 账户包以用户口令派生密钥加密；明文助记词 / 私钥只在内存中短暂存在。
- 签名与交易须在扩展审批页确认；解锁态不会跳过审批。
- 扩展不保证第三方 RPC、DApp、浏览器环境或用户设备不存在风险；用户应使用可信节点、核对签名内容并妥善保管备份。
- 任何安全措施都无法完全消除设备被恶意软件、浏览器漏洞或用户误操作攻破的风险。

---

## 8. 儿童

本扩展面向具备加密资产风险认知的成年用户，不面向儿童设计。未成年人应在监护人指导下使用，并遵守所在地法律。
