# 子项目：Web（`apps/web`，`@plugin/web`）

- **本地类型**：`src/types/*.ts`，聚合出口 **`src/types/index.ts`**（`export type * from './…'`）；引用 **`@/types`**（与 `tsconfig` 的 `@/*` 一致）。
- **栈**：Next.js App Router、React、viem、TanStack Query、**UnoCSS**（`@unocss/postcss` + `uno.config.ts`，与 [UnoCSS · Next.js](https://unocss.dev/integrations/next) 一致：`globals.css` 中 `@unocss all`，`layout` 引入 `@unocss/reset/tailwind.css`）；与扩展共用的 UI 组件见 [**@plugin/ui**](./ui.md)（`next.config.ts` 已 `transpilePackages`）。
- **技术方案总览**：[TECHNICAL-SOLUTION.md §4.2](./TECHNICAL-SOLUTION.md)。
- **页面**：`/`（首页导航）、[`/wallet`](../../apps/web/src/app/wallet/page.tsx)（EIP-6963 / EIP-1193 联调）、[`/balances`](../../apps/web/src/app/balances/page.tsx)（**多链余额查询入口**：EVM / Tron / BTC 三张链选择卡片）及三个独立查询页 [`/balances/evm`](../../apps/web/src/app/balances/evm/page.tsx)、[`/balances/tron`](../../apps/web/src/app/balances/tron/page.tsx)、[`/balances/btc`](../../apps/web/src/app/balances/btc/page.tsx)（每页只展示当前链的表单与结果，只向 `POST /api/v1/balances/query` 提交一个 group；地址自动去重与基础校验、每链 20 条限制、请求取消、分页 / CSV 导出、空态与部分失败提示，原始 JSON 收进调试区；旧 `/gateway` 308 重定向到 `/balances`）、[`/account`](../../apps/web/src/app/account/page.tsx)（**登录与交易广播**：连接扩展 → 获取 challenge → `personal_sign` → Bearer 会话 → `eth_signTransaction` → 服务端 `POST /api/v1/tx/broadcast`）。EVM 原生余额会标注实际数据源（`source: rpc | etherscan`）；ERC-20 不可达时显示 stale / 缓存与可操作提示。
- **余额查询实现**：链元信息与路由在 [`src/lib/balancesFamilies.ts`](../../apps/web/src/lib/balancesFamilies.ts)，单链页面在 [`src/components/balances/balancesFamilyPage.tsx`](../../apps/web/src/components/balances/balancesFamilyPage.tsx)，表单与校验在 [`src/lib/balancesApi.ts`](../../apps/web/src/lib/balancesApi.ts)，请求状态机（取消、401 自动降级匿名）在 [`src/hooks/useBalancesQuery.ts`](../../apps/web/src/hooks/useBalancesQuery.ts)，表格 / 分页 / CSV 与展示格式在 [`src/components/balances/*`](../../apps/web/src/components/balances/) 与 [`src/lib/balancesFormat.ts`](../../apps/web/src/lib/balancesFormat.ts)；Bearer token 读写统一走 [`src/lib/authSession.ts`](../../apps/web/src/lib/authSession.ts)。
- **登录会话（MVP）**：`/account` 与 `/balances/*` 共用 `sessionStorage` 中的 Bearer token；`/account` 刷新后通过 `GET /api/v1/auth/me` 恢复。服务端 CORS 已改为 `SERVER_CORS_ORIGINS` 白名单（开发默认 `http://localhost:3000`）；跨域部署时必须把实际 Web Origin 配置到服务端，生产前仍需迁移 HttpOnly Cookie + CSRF 并补 Web CSP（见 [BACKLOG.md](./BACKLOG.md) P4-5、[security.md](./security.md)）。
- **职责**：展示与业务流程；链上只读优先走服务端；不持有用户私钥。
- **产品对照**：[prd-web.md](../product/prd-web.md)；整体见 [PRODUCT-OVERVIEW.md](../product/PRODUCT-OVERVIEW.md) §A4、§A8。
